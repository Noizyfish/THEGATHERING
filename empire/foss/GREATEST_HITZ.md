# FOSS GREATEST HITZ — the open-source stack the NOIZY empire runs on

> 53 hits (38 core · 15 optional ○) across 7 tiers. One manifest — `empire/foss/hitz.json` — renders this page, the Brewfile, requirements and the doctor. Generated by `scripts/build-foss.mjs`; edit the JSON, not this file.

**Why a list?** Sovereignty is a supply chain. Every box RSP's voice passes through — bus, surface, STT, DAW glue, remote, mirror, backup — must be something we can read, fork and run on our own metal. This page is the audit.

## Rules

- Every link in the chain is FOSS unless listed under nonfoss, with a FOSS alternative named.
- license = SPDX id of the code. Model weights get their own `weights` field — code and weights often differ.
- install = how it lands on GOD (M2 Ultra): brew|cask|pip|npm|cargo|docker|manual.
- usedBy = which NOIZY pieces depend on it (noizystdz, engr, noizybeast, empire, gabriel, lucy, demo).
- verify = a command that proves it is present. scripts/foss --check runs them all.

## One command on GOD

```sh
scripts/foss install            # Homebrew bundle + uv venv + npm globals (core tier)
scripts/foss install --optional # + TTS research, Ardour, Node-RED, Headscale…
scripts/foss check              # doctor: runs every verify, prints ✅/❌ per hit
scripts/foss licenses           # SPDX histogram
```

## Voice-model weights — the legal line

NOIZYVOX is trained **only** on consent-signed NOIZYSTDZ sessions (`engine/consent.py`, scope `train`). The TTS *recipes* above are MIT/Apache; their *pretrained weights* are not all commercial-clean (F5-TTS is CC-BY-NC). Rule: fine-tune from scratch or from Apache/MIT weights (Kokoro, Chatterbox) before anything ships to Nicholas, LINA's listeners, or a client.
